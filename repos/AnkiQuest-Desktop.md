## This repository

AnkiQuest-Desktop holds the Anki desktop add-on and its releases.

- **Layout.** `addon/`: the add-on, Python because Anki requires it. `tests/`: add-on tests (Python). `tools/package-addon`: the add-on packager (`cargo run --manifest-path tools/package-addon/Cargo.toml -- --output <file>`), a Rust workspace of its own. `art-exports.json`: the add-on poses and the retired copies in `assets/retired/addon/`. Python is only the add-on and its tests; write every other tool, check and test in Rust.
- **Screenshots and banner** are generated. `tests/draw_screenshots.py` draws `docs/screenshots/desktop-*.png` from `tests/screenshots/data.json`; `tools/banner`, a Rust workspace of its own, draws `docs/graphics/` from them and the duo master in an AnkiQuest-Server checkout. A change to a screen regenerates both (commands in the README) in the same pull request; never edit or capture them by hand. The harness is a test (each screenshot is a test case), not a tool, so it stays in Python next to the add-on tests.
- **No server code.** The server, web pages, API examples, shared fixtures, art masters and deployment live in AnkiQuest-Server; open those changes there.
- **Server snapshot.** The add-on tests read copies of AnkiQuest-Server's `tests/fixtures/*.json` (in `tests/fixtures/`) and of the API examples they use (in `tests/api-examples/`), pinned to the commit in `tests/ankiquest-server.sha`. The add-on poses are exports of that commit's masters. CI fails while a copy differs from the pinned commit. Never edit a copy: change Server first, then bump the pin and the copies together ([docs/desktop.md](docs/desktop.md#server-snapshot)).
- **Releases** are the `addon-*` tags and GitHub releases of this repository; AnkiWeb lists the add-on as 414948448.
- **Checks to run** before pushing, for what you changed: `python -m unittest discover -s tests` for the add-on; `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace`, each with `--manifest-path tools/package-addon/Cargo.toml` for the packager and with `--manifest-path tools/banner/Cargo.toml` for the banner tool. Leave the full matrix to CI.
