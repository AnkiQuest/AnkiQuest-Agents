## This repository

AnkiQuest-Desktop holds the Anki desktop add-on and its releases.

- **Layout.** `addon/`: the add-on, Python because Anki requires it. `tests/`: add-on tests (Python). `tools/package-addon`: the add-on packager (`cargo run --manifest-path tools/package-addon/Cargo.toml -- --output <file>`), a Rust workspace of its own. Python is only the add-on and its tests; write every other tool, check and test in Rust.
- **Screenshots and banner** are generated. `tests/draw_screenshots.py` draws `docs/screenshots/desktop-*.png` from `tests/screenshots/data.json`; AnkiQuest-Dev's shared `ankiquest-banner` draws `docs/graphics/` from them and the duo master at the pinned server commit (`docs/graphics/banner.toml`). A change to a screen regenerates both (commands in the README) in the same pull request; never edit or capture them by hand. The harness is a test (each screenshot is a test case), not a tool, so it stays in Python next to the add-on tests.
- **No server code.** The server, web pages, API examples, shared fixtures and deployment live in AnkiQuest-Server, and companion art in AnkiQuest-Art; open those changes there. The add-on's pictures come from the AnkiQuest-Art release pinned in `ankiquest-art.json`.
- **Server data comes from server master.** The add-on tests read AnkiQuest-Server's `tests/fixtures/*.json` and `docs/api/examples/*.json` from its `master`: `cargo run --manifest-path tools/package-addon/Cargo.toml -- server-data` copies them into `tests/fixtures/` and `tests/api-examples/` (not committed), and CI does so before the tests ([docs/desktop.md](docs/desktop.md#server-data)). Never add a fixture or example here: change Server first. A server change that breaks the add-on's tests is fixed in the same change, or the add-on is updated right after.
- **Releases** are the `addon-*` tags and GitHub releases of this repository; AnkiWeb lists the add-on as 414948448.
- **Checks to run** before pushing, for what you changed: `python -m unittest discover -s tests` for the add-on; `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace`, each with `--manifest-path tools/package-addon/Cargo.toml` for the packager. Leave the full matrix to CI.
