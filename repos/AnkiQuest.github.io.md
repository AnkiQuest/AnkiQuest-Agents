## This repository

AnkiQuest.github.io is the AnkiQuest art gallery on GitHub Pages (coming).

- **Poses only as exported copies.** Every picture here is generated from its master in AnkiQuest-Server `static/<companion>/` by the exporters and hash-checked; never commit a hand-made copy. Delete a copy that was renamed, retired or is no longer used.
- **Pages** are TypeScript, as the server's web pages are.
