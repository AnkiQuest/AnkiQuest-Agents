## This repository

AnkiQuest-Sync holds AnkiQuest's scheduled GitHub Actions jobs and the Rust tools they run (`tools/`).

- **Jobs.** `sync` (`.github/workflows/sync.yml`): merges upstream into branch `sync/<owner>/<repo>` of each fork, regenerates `AGENTS.md` there, and opens or updates one pull request from it into `master`, one matrix entry per fork; the logic is `tools/fork-sync`. `watch`: moves pins and opens issues for the sources in `watched.json` (merged sources are rows of the `sync` matrix). `agents` (`.github/workflows/agents.yml`): writes each repository's `AGENTS.md` from AnkiQuest-Agents and opens a pull request where it differs; its targets are the `TARGETS` map in that workflow. `art`: when AnkiQuest-Art publishes a release, writes its `ankiquest-art.json` into every repository that uses art and opens a pull request `chore(art): use AnkiQuest-Art <tag>`. Both `agents` and `art` turn on auto-merge for their pull requests (`tools/auto-merge.sh`). `mirror` (in `sync.yml`): pushes each branch in `mirrors.json` to its source's commit; the logic is `source-watch mirror`.
- **Token.** Every job writes to other repositories with `FORK_SYNC_TOKEN`; `GITHUB_TOKEN` can't. Never print it. Its scopes are listed in the README; widen them there when a job needs a new repository.
- **Never force-push** or write a fork's `master` directly; everything goes through a pull request or an issue. The jobs only add commits to their own branches (`sync/*`, `agents-sync`, `art-release`), so people can push fixes there. The one exception is a mirror in `mirrors.json`: a plain push of the source's commit, never to a default branch; a mirror that isn't behind its source fails the job.
- **Shell.** Keep each step a few lines of glue. Logic that grows beyond that moves to a Rust tool in this repository.
- **Checks to run** before pushing: `nix develop -c actionlint` and `nix develop -c zizmor .` (the `check` workflow runs both), and `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` in each tool you changed; run the job by hand (Run workflow) after merging.
