## This repository

AnkiQuest-Dev is the development environment for every AnkiQuest repository, on any machine: one dev shell per kind of repository (`devShells.<system>.{default,server,desktop,android,android-emulator,android-backend,anki}`), NixOS on WSL (`nixosConfigurations.ankiquest-wsl`), modules for NixOS and nix-darwin, a winget configuration for Windows and a dev container. The other repositories' flakes take their shells, formatter and pins from here.

- **Layout.** `flake.nix`: the outputs (`lib`, `overlays`, `packages`, `devShells`, `nixosModules`, `darwinModules`, `nixosConfigurations`, `checks`). `shells/toolchains.nix`: every pinned version (Rust, Android SDK and NDK, JBR, Node, Python), each next to the repository file it follows. `shells/default.nix`: the dev shells. `nixos/roles` and `nixos/modules`: what a NixOS machine needs, exported as `nixosModules.ankiquest-dev`; `nixos/hosts/ankiquest-wsl`: the WSL host. `darwin/`: `darwinModules.ankiquest-dev`. `windows/`: the winget configuration, generated from `shells/toolchains.nix`. `.devcontainer/`: the dev container.
- **One source.** Shared Nix tooling (toolchain pins, dev shells, formatter and its check, nix-ld and direnv) lives here only; other repositories take it as the `ankiquest-dev` input. A repository's own packages and NixOS service modules stay in that repository, so nothing here depends on another AnkiQuest repository.
- **Pins follow the repositories.** When a repository changes a version it pins (`rust-toolchain.toml`, `gradle/libs.versions.toml`, `gradle/gradle-daemon-jvm.properties`, a CI workflow), change the matching value in `shells/toolchains.nix` and regenerate `windows/configuration.dsc.yaml` (`nix build .#windows-configuration`). Update one flake input at a time with `nix flake update <input>`.
- **Nix only.** Configuration is Nix, formatted with alejandra. Generated files come from Nix expressions or Rust. Shell and PowerShell stay a few lines of glue; anything larger becomes Rust.
- **Nothing private.** Signing keys, `keystore.properties`, `google-services.json`, tokens and proprietary SDKs (the Garmin Connect IQ SDK) are installed by hand, as the README says, and never committed.
- **Checks to run** before pushing: `nix flake check --all-systems`, `alejandra --check .`, and `nix develop .#<shell>` for each shell you changed.
